# Leads Tracker 🔗

A simple Chrome extension built with HTML, CSS, and JavaScript to save and track links to tabs related to ongoing tasks and projects.

## ✨ Features
- Save links to ongoing work and projects
- Keep track of useful website URLs
- Easily access saved links when needed
- Simple and lightweight interface

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Chrome Extension APIs (Manifest V3)

## 🚀 Installation
1. Clone this repository:
   ```bash
   https://github.com/Anika-Aktar/lead-extension.git
   ```
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extension's project folder.

## 💡 Purpose
Built to make managing work-related tabs and keeping track of useful links easier.
